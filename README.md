# Учебный архив кафедры статистической физики

Статический русскоязычный сайт для 3–6 курсов (5–12 семестры) на GitHub Pages. Каталог автоматически строится по дереву `materials/`, включая вложенные папки любой глубины. Сервер приложений, база данных, API-ключи, npm и сторонние библиотеки не нужны.

## 1. Публикация на GitHub

1. Распакуйте архив. На [github.com/new](https://github.com/new) создайте **пустой публичный репозиторий** `statphys-materials` (не добавляйте README, .gitignore и лицензию при создании).
2. В Terminal на macOS/Linux или Git Bash на Windows откройте распакованную папку `statphys-site`. Убедитесь, что Git установлен. Выполните команды, заменив `USERNAME` на свой логин (и название репозитория, если оно другое):

   ```bash
   git init -b main
   git add .
   git commit -m "Initial educational catalogue"
   git remote add origin https://github.com/USERNAME/statphys-materials.git
   git push -u origin main
   ```

   Если Git запрашивает авторизацию, используйте GitHub CLI (`gh auth login`), Git Credential Manager или персональный токен вместо пароля. GitHub Desktop — альтернативный способ опубликовать локальный репозиторий. Важно сохранить скрытую папку `.github` вместе с её содержимым.
3. Откройте репозиторий на GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. На вкладке **Actions** откройте `Publish educational catalogue` → **Run workflow** → выберите `main` → **Run workflow**. Если первое выполнение до настройки Pages завершилось ошибкой, этот повтор необходим. Если Actions отключены, включите их в настройках репозитория.
5. После успешного выполнения адрес сайта будет указан в Settings → Pages. Обычно: `https://USERNAME.github.io/statphys-materials/`. Не копируйте этот пример буквально.

Дальнейшие изменения в `main` автоматически запускают сборку и публикацию. Если хотите использовать другое имя основной ветки, измените `branches: [main]` в `.github/workflows/pages.yml`. При проблемах проверьте журнал Actions и настройки среды `github-pages`.

## 2. Добавление учебных материалов через браузер

На опубликованном сайте выберите курс, семестр и нужную папку. Внизу есть ссылки «Загрузить файлы», «Создать раздел», «Открыть папку»; они ведут в соответствующие разделы GitHub. Для записи необходим доступ к репозиторию. Студенты могут читать сайт без GitHub-аккаунта.

**Загрузить файл:** в папке GitHub нажмите Add file → Upload files, выберите документы, затем Commit changes (в `main`, либо через pull request с последующим слиянием). Если редактирование основной ветки защищено, работайте через pull request.

**Создать новый раздел:** в папке нужного семестра нажмите Add file → Create new file. В поле имени введите, например, `Квантовая статистика/.gitkeep` и сохраните изменения. Git не хранит пустые папки, поэтому `.gitkeep` нужен до появления первого файла. Можно ввести `Квантовая статистика/Лекции/.gitkeep`, чтобы создать сразу вложенный раздел. Служебные файлы с точкой не показываются студентам.

**Удалить или переименовать:** используйте инструменты GitHub (или Git локально). Сайт обновится после следующей успешной сборки. Старая история коммитов может сохранять удалённые материалы.

Не загружайте документы в `site/`: каталог читает только `materials/3`, `materials/4`, `materials/5`, `materials/6`. Добавляйте учебные материалы внутри соответствующего семестра, например `materials/3/5 семестр — осенний/Статистическая физика/Лекция 1.pdf`. Названия могут быть кириллическими, со пробелами и символами `#`, `%` и т.п.; избегайте символов, запрещённых на Windows. При большом количестве файлов удобнее Git/GitHub Desktop.

## 3. Структура проекта

```text
statphys-site/
├── .github/workflows/pages.yml  # автоматическая публикация
├── scripts/build.py            # построение каталога (Python)
├── site/
│   ├── index.html               # HTML-шаблон
│   ├── style.css                # оформление и адаптивность
│   └── app.js                   # навигация и поиск
├── materials/
│   ├── 3/
│   │   ├── 5 семестр — осенний/
│   │   │   ├── Лекции/
│   │   │   │   ├── .gitkeep
│   │   │   │   └── Пример учебного файла.txt
│   │   │   ├── Семинары и задачи/
│   │   │   └── Литература/
│   │   └── 6 семестр — весенний/
│   ├── 4/
│   │   ├── 7 семестр — осенний/
│   │   └── 8 семестр — весенний/
│   ├── 5/
│   │   ├── 9 семестр — осенний/
│   │   └── 10 семестр — весенний/
│   └── 6/
│       ├── 11 семестр — осенний/
│       └── 12 семестр — весенний/
├── .gitignore
└── README.md
```

В каждом из восьми семестров созданы папки «Лекции», «Семинары и задачи», «Литература». Дополнительно созданы разделы дисциплин по предоставленным учебным планам СПбГУ 25/5350/1 и 25/5511/1: базовая часть, профильные дисциплины по выбору, общие дисциплины по выбору (где предусмотрены), практики и итоговая аттестация. См. [CURRICULUM.md](CURRICULUM.md) с перечнем и страницами источников. Факультативы и блоки других профилей не включены. Прежние общие папки сохранены. Демонстрационный TXT сохранён в 5-м семестре. Удалите демонстрационный TXT после загрузки реальных материалов. Никаких реальных лекций или официальной символики в проекте нет. Исходные PDF учебных планов не включены в публичный каталог.

## 4. Локальный запуск

Нужен Python 3.10+ (без установки библиотек). Из корня проекта:

```bash
python3 scripts/build.py
python3 -m http.server 8000 --directory _site
```

В Windows при необходимости замените `python3` на `py -3`. Откройте `http://localhost:8000`. Для обновления каталога повторите первую команду и перезагрузите страницу. `_site/` — генерируемый результат; не нужно коммитить его или редактировать вручную. Можно также открыть `_site/index.html` непосредственно в браузере: список материалов встроен в HTML, а файлы и стили лежат рядом.

Для проверки ссылок управления в локальной сборке можно указать `python3 scripts/build.py --repository USERNAME/statphys-materials --branch main`.

## 5. Форматы, ограничения и доступ

- PDF и растровые изображения открываются в новой вкладке; остальные поддерживаемые форматы предлагаются для скачивания. Среди них DjVu, Word, Excel, PowerPoint, TXT, TeX, Python, Jupyter, ZIP, MP3, MP4 и другие. Точный список — `ALLOWED` в `scripts/build.py`. HTML и SVG намеренно не публикуются из папки учебных материалов. Неизвестные расширения пропускаются с сообщением в журнале сборки.
- Ограничение GitHub: через браузер — 25 MiB на файл, через Git — до 100 MiB. Опубликованный сайт GitHub Pages ограничен 1 GB, поэтому большие видеоархивы следует хранить отдельно. Git LFS в этой сборке не поддерживается; скрипт отклоняет LFS-указатели.
- Репозиторий и сайт при бесплатном публичном размещении доступны всем, а не только студентам. Публикуйте лишь материалы с разрешением правообладателя, без персональных данных. Не размещайте пароли, токены и приватные документы. Для ограниченного доступа нужна иная схема размещения или подходящий корпоративный план с настройками приватности.
- Управление файлами выполняется в GitHub, не через собственную форму загрузки на статическом сайте. Выдавайте право записи только доверенным редакторам (Settings → Collaborators); остальные могут предлагать изменения через pull request, если это уместно.
